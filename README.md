# MARHI Параметрика

Интерактивный конфигуратор параметрического потолка и бумажного модуля.

## Версии сайта

| Страница | Содержимое |
| --- | --- |
| [index.html](index.html) | Исходный белый потолок: линейный аттрактор, отключаемые правила, тени, шесть тросовых подвесов |
| [cell.html](cell.html) | Отдельная ячейка, объём, размеры, развёртка по граням с клапанами, печать A4, экспорт SVG и OBJ |
| [inverted.html](inverted.html) | Потолок с углублениями вниз; настройки сохраняются отдельно |
| [versions/linear-before-paper.html](versions/linear-before-paper.html) | Сохранённая версия линейного потолка до добавления бумажной модели и переходов |

## Как открыть

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `index.html` в браузере. Установка и интернет не нужны. Все соседние файлы JS/CSS должны оставаться рядом с HTML. Фотография помещения встроена в страницы потолка.

## Ссылка для преподавателя

Один раз откройте **Settings → Pages** этого репозитория:

1. В **Source** выберите **Deploy from a branch**.
2. В **Branch** выберите **main**, папку **/ (root)** и нажмите **Save**.
3. Дождитесь завершения публикации. GitHub покажет действующую ссылку.

После включения Pages ожидаемый адрес: https://matvey3251.github.io/MARHI-Parametrika/

Адрес заработает только после успешной публикации. Преподавателю достаточно открыть его в браузере; скачивать код и входить в GitHub не требуется.

## Возможности

- Линейный аттрактор через всю длину потолка с настройками смещения и наклона.
- Четыре независимых правила: уменьшение ячеек к линии, нарастание глубины, продольная волна, сужение отверстий.
- Белый материал, управление силой и мягкостью теней, направлением и высотой света.
- Просмотр геометрии, план снизу и концептуальная примерка на фото помещения.
- Сохранение настроек в JSON, загрузка проекта, снимок PNG, геометрия OBJ.
- Выбор ячейки из потолка для бумажного макета.

## Бумажная модель

На странице потолка выберите ячейку в блоке «Бумажный модуль». Во второй странице задайте размеры, масштаб и клапаны. Развёртка состоит из отдельных плоских граней. Соединяйте одинаковые номера стыков S и C. При включённой продольной волне бумажный модуль получает плоский обод; это отмечается в интерфейсе.

Печатайте на A4 при **100% без подгонки**. Проверьте линейкой контрольный отрезок 50 мм. Если деталь не помещается, увеличьте знаменатель масштаба. Автоматического уменьшения нет. Толщина бумаги не учитывается — сначала соберите одну пробную ячейку.

Размеры помещения условные. Модель предназначена для разработки концепции; монтажные узлы и несущая способность конструкции требуют обмеров и расчёта.
