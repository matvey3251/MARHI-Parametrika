# Отчёт Никиты: управление параметрикой

Дата: 6 ноября 2026 года. Область: обе страницы потолка — исходный и с углублениями вниз.

## Решение

Все 18 числовых факторов и четыре независимых правила сохранены. Факторы описывают разные свойства: размеры, структуру рисунка, деформацию, отверстия, подвес и освещение. Удаление факторов сократило бы выразительность модели и усложнило бы воспроизведение ранее сохранённых проектов. Вместо этого управление стало точнее, а смысл коэффициентов — понятнее. Изменение визуальной иерархии разделов выполняется совместно с Артёмом.

## Что изменено

- Рядом с каждым ползунком добавлено поле точного числового ввода с исходными единицами.
- Значение применяется при Enter, потере фокуса или подтверждении изменения поля. Escape возвращает текущее значение ползунка, отменяя ещё не применённый ввод.
- Пустое или нечисловое значение не передаётся движку: поле возвращается к текущему числу. Значения за пределами диапазона и между шагами нормализует исходный HTML-ползунок.
- Числовое поле блокируется вместе с ползунком выключенного правила.
- После пресета, сброса, загрузки JSON и перемещения линии на плане новые поля автоматически подключаются к заново созданным ползункам.
- Добавлены объяснения назначения всех факторов. Для отверстий явно указано, что доля относится к линейному размеру, а не площади. Для наклона указано, что это коэффициент, а не градусы.
- Поля имеют доступные названия; ползунок и числовой ввод связаны с общей поясняющей подписью через aria-describedby. Ползунок сообщает значение с единицами через aria-valuetext.
- Введена CSS-переменная --range-progress для отображения положения ползунка.

| Глубина складки | depth | 0,08–0,65 | 0,01 | м, базовая глубина |
| Количество ячеек | count | 60–320 | 1 | шт., общее количество |

| Высота волны | waveAmplitude | 0–0,35 | 0,01 | м, амплитуда |
| Период волны | wavePeriod | 0,8–5 | 0,1 | м, длина повторения |
| Сужение отверстий | openingGain | 0–0,8 | 0,01 | уменьшение отверстий около линии |
| Сила теней | shadowStrength | 0–1 | 0,01 | контраст светотени; 0 — без затенения |

Четыре переключаемых правила сохранены: сгущение ячеек, изменение глубины, продольная волна, сужение отверстий. Выключенное правило сохраняет свои числа для последующего включения.

## Совместимость и реализация

Изменения изолированы в controls.js. Файл не создаёт вторую модель состояния: числовой ввод передаёт значение исходному ползунку, который вызывает существующий обработчик движка. Формулы, начальные значения, ключи JSON, формат импорта, экспорт OBJ/PNG, подвесы и геометрия бумажной модели этим файлом не изменяются.

MutationObserver наблюдает структуру панели и только атрибут disabled. Стиль прогресса и aria-valuetext не входят в фильтр атрибутов. disabled числового поля записывается только при реальном изменении, что предотвращает повторяющийся цикл наблюдателя. WeakMap не удерживает удалённые ползунки после перерисовки. Повторное сканирование существующих полей синхронизирует их, не добавляя дублирующих элементов и обработчиков.
